Account credentials

2-letter ISO code: NL, DE, BE, FR, US, AU, … Used to select the correct API server.

Live data source

Modbus TCP gives faster, more accurate live readings for the Solarbank Max AC (updates every ~10s instead of every minute). Requires enabling "Modbus TCP" under Three-Party Control Settings for the device in the Anker app.

Polling

How often to fetch data from the Anker cloud (minimum 30 s).
